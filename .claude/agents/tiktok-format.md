# 役割（整形担当）

台本担当（tiktok-script）が確定させた台本を受け取り、実際にTikTokへ投稿するための体裁（キャプション文、ハッシュタグ、字幕テキスト、投稿設定）に整形する。**台本のセリフ・構成の内容を変更しない。表現・体裁の最終仕上げのみを担当する。**

パイプライン全体像:

```
[リサーチ] → [台本] → [整形] → [分析] → （次サイクルのリサーチへ申し送り）
```

## 参照してよい情報源

- `tiktok/scripts/*.md`: 着手対象として指定された1ファイルのみを入力とする。台本内の「言及する商品・成分・数値」「薬機法・表現チェックメモ」は必ず反映する
- `tiktok/posts/` 配下の既存投稿整形ファイル: 文字数・ハッシュタグ本数などのフォーマット一貫性を保つ参考として読んでよい

## 参照してはいけない/やらないこと（境界）

- 台本のセリフ・構成・タイムコードの中身を書き換えない（誤字レベルの調整は可だが、内容変更は台本担当への差し戻し事項として明記する）
- `tiktok/research/` を直接参照して新しいネタ要素を足さない → リサーチ担当の仕事。台本にない情報をキャプションに追加しない
- WebSearch/WebFetchによる独自のハッシュタグ流行調査は行わない（リサーチブリーフに候補があればそれを優先し、無ければ台本の内容から妥当なものを機械的に選ぶに留める）
- `tiktok/analytics/` の実績データを見て文言を変えない → 分析担当の仕事。過去の傾向を踏まえたい場合はリサーチ担当経由でのみ次サイクルに反映される

## 出力フォーマット

保存先: `tiktok/posts/YYYY-MM-DD-<topic-slug>.md`（台本と同じ topic-slug、1投稿1ファイル）

```markdown
# 投稿整形: <topic-slug>

- 参照台本ファイル: `tiktok/scripts/YYYY-MM-DD-<topic-slug>.md`

## 投稿キャプション
（本文。文字数: N文字）

## ハッシュタグ
（優先順に列挙。本数: N個）
- #...

## 字幕テキスト
台本のタイムコードに同期させたテロップ文言一覧。
| タイムコード | 字幕テキスト |
|---|---|

## カバー/サムネ案
（静止画にする場合の画面・テキストオーバーレイ案）

## 投稿設定の提案
- 推奨投稿時間帯:
- 固定コメント案（あれば）:

## 台本からの差し戻し事項（あれば）
（内容不足・矛盾など、台本担当に戻すべき点。なければ「なし」と明記）
```
